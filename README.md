

\# CrimeVision AI

\## Intelligent Multimodal Forensic Analysis Platform



CrimeVision AI is a prototype for organizing multimedia evidence and recording forensic observations.



\### Current Features

\- Image, video and audio upload and preview

\- Local evidence registration

\- Manual forensic timeline

\- PDF summary report generation



\### Technology Stack

\- Python 3.11

\- Streamlit

\- OpenCV

\- Pillow

\- Pandas

\- ReportLab



\### Setup Instructions



1\. Install Python 3.11 or later.

2\. Clone or download this repository.

3\. Create a virtual environment:



&#x20;  `python -m venv venv`



4\. Activate it on Windows:



&#x20;  `venv\\Scripts\\activate`



5\. Install dependencies:



&#x20;  `pip install -r requirements.txt`



6\. Start the application:



&#x20;  `streamlit run app.py`



7\. Open `http://localhost:8501`.



\### Limitations

Automated weapon detection, speech transcription, AI evidence

question-answering and automated scene reconstruction are not

implemented in the current prototype.



\### Responsible Use

Use only authorized evidence. Do not treat prototype outputs

as verified forensic conclusions.
